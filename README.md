# 🎲 루미큐브 (Rummikub) AI 대전 웹 앱

별도의 서버 실행 없이, 웹 브라우저에서 바로 스마트한 AI 대전 상대들과 루미큐브를 즐길 수 있는 단일 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **🚀 100% 브라우저 구동 (백엔드 서버 필요 없음)**
   - 소켓 서버나 데이터베이스 연결 없이, 명령어 단 한 줄(`npm run dev`)로 즉시 플레이할 수 있습니다.
   - AI 1명 ~ 3명 대전 상대를 자유롭게 선택 가능합니다.

2. **🧩 루미큐브 핵심 규칙 검증 엔진 (Rule Validation Engine)**
   - **그룹(Group)**: 동일한 숫자, 서로 다른 3~4가지 색상 (조커 포함)
   - **런(Run)**: 동일한 색상, 연속된 3개 이상 숫자 (조커 포함)
   - **30점 첫 등록 규칙**: 첫 등록 시 내려놓는 패들의 합이 **최소 30점 이상**이어야 함
   - **시각적 비주얼 경고**: 3장 미만이거나 잘못된 세트는 붉은 테두리와 흔들림(shake) 애니메이션으로 경고

3. **🎨 고급 3D 디자인 & 편리한 컨트롤**
   - 카지노 다크 벨벳 테이블 디자인 & 3D 루미큐브 타일 입체 효과
   - **손패 정렬**: `색상별 정렬`, `숫자별 정렬` 지원
   - **되돌리기 (Undo)**: 배치 중 실수가 있었을 때 턴 시작 상태로 원상복구

---

## 🚀 실행 방법 (극초보자 가이드)

> [!NOTE]
> 남건! 아래 명령어를 터미널 창에 입력하실 때는 위아래의 ```` ```bash ```` 기호는 빼고, 네모 박스 안의 진짜 영어 명령어만 복사해서 붙여넣으세요!

### 1단계: 실행하기 (Vite Dev Server)
1. 터미널 창을 엽니다.
2. 아래 명령어를 입력합니다:

```bash
cd client
npm run dev
```

3. 화면에 나오는 주소 (예: `http://localhost:5173`) 로 브라우저를 접속하시면 바로 플레이하실 수 있습니다!
