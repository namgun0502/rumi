# 🎮 루미큐브 웹 앱 — 첫 등록(Initial Meld) 30점 규칙 및 검증 오류 수정 계획서

## 1. 개요
루미큐브 정식 규칙에 따라, 첫 등록(Initial Meld) 시 발생하는 30점 판정 및 보드 타일 혼용 오류를 수정합니다.

## 2. 기존 문제점 (오류 원인)
1. **보드 세트 ID 비교 방식의 오류**: 기존 코드에서는 세트 `id`로 신규 세트 여부를 판별하여, 기존 보드 세트에 타일을 덧붙이거나 드롭하여 새 세트를 형성할 때 첫 등록 검증이 제대로 이뤄지지 않거나 오작동함.
2. **보드 타일 재조합 허용 오류**: 첫 등록 시에는 보드의 기존 타일을 건드리거나 조합할 수 없으나, 기존 타일을 조합해서 30점을 완성해도 통과되는 규칙 위반 발생.
3. **손패 타일 전용 검증 부재**: 첫 등록 30점은 오직 플레이어의 **손패(Rack)에서 가져온 타일만으로 구성된 순수 세트들의 점수 합**이어야 함.

## 3. 주요 수정 내역
1. **`App.jsx` 첫 등록 검증 로직 개편**:
   - 이번 턴에 새로 보드판에 올려놓은 타일 중, **오직 본인의 원래 손패(`turnSnapshot.rack`) 타일들로만 완전하게 구성된 세트들**을 추출.
   - 첫 등록 전 상태라면, 기존 보드의 타일을 건드렸는지(세트 해체/타일 이동) 체크하여 기존 보드 타일 조작이 있었을 경우 첫 등록 불가 안내.
   - 순수 손패 세트들의 점수 합산(`validateInitialMeld`)이 30점 이상인지 정확하게 판정.

2. **`ruleEngine.js` 점수 계산 보강**:
   - `calculateSetScore`에서 런(Run)과 그룹(Group) 내 조커가 대체하는 실제 숫자 점수를 더욱 정교하고 안전하게 계산하도록 보강.
